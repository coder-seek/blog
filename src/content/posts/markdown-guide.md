Markdown 是一种轻量级标记语言，让你专注于内容而非排版。

## 基础语法

### 标题

用 `#` 表示标题层级：

```md
# 一级标题
## 二级标题
### 三级标题
```

### 强调

**加粗**和*斜体*是表达重点的方式。

### 代码

行内代码用反引号：`console.log("hello")`。

代码块用三个反引号并指定语言：

```javascript
function greet(name) {
  return `Hello, ${name}!`;
}
```

### 引用

> 这是一段引用文字。
> 可以跨越多行。

### 列表

无序列表：

- 第一项
- 第二项
  - 嵌套项

有序列表：

1. 第一步
2. 第二步
3. 第三步

### 链接和图片

[链接文字](https://example.com)

![图片描述](https://example.com/image.jpg)

## 写在最后

Markdown 的核心理念是：**简单即是力量**。掌握这些基础语法，你就能写出漂亮的文章。
